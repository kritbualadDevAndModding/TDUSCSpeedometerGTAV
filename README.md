# TDU Solar Crown Speedometer GTA V

GTA V Mod Test Drive Unlimited Solar Crown HUD

**Description**

This is my first experience creating a script mods first time, a speedometer HUD for Test Drive Unlimited Solar Crown. I had previously experimented with Assetto Corsa before deciding to create a speedometer mod for GTA 5.

**Features**
- Version HUD ( Demo , Release , Season 5 V1 , Season 5 V2 )
- Rev RPM
- Drift HUD for Demo HUD only
- Handbrake HUD
- Turn Signal HUD
- Gear HUD
- Throttle and Brake HUD for Season 5 V2 only
- Headlight HUD for Season 5 only
- Units
- Language Units (Denmark / Norway , Nederlands , Russian , Turkish , Ukriane ,  Vietnamese)
- ABS HUD
- TCS HUD
- Show Debug Name Cars

**How to Install**
-------------------------------------------------------------------
**`scripts`** folder.
- Place it in the main **`GTA V`** game folder.

**`script_txds`** folder.

- Open **`OpenIV`** > Select **`GTA V`**. Go to **`mods\update\update.rpf\x64\textures\script_txds.rpf`**


**Using the Max RPM add-on is very easy.**

You do not need to exit the game. you simply need to activate the Console first. **`ScriptHookVDotNet.ini`** > **`ConsoleKeyBinding`** (Default F4)

Go to **`scripts\TDUSCSpeedometerGTAVSetRPM\Example.cfg`**.

Then, add the desired line.

Example:
--------------------------------------------
**`Pfister Comet\comet2\8000`**

Pfister Comet = Custom Vehicle Name

comet2 = Spawn Name

8000 = Max RPM


**`Save`** the file.

Then, open the in-game console, type **`Reload()`**, and press **`Enter`**.

Once the script has reloaded, open the TDUSCSpeedoV menu and check the **`Show Debug Name Cars`** option.

------------------------------
